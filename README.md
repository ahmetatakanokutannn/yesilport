# YeşilPORT

Turkish green logistics portal for Yeditepe University TTO A.Ş. and Teknopark Istanbul R&D evaluation.

## Stack

- Frontend: React 18, TypeScript, Vite, Tailwind CSS, React Router, i18next, Axios
- Backend: Node.js, Express, TypeScript, PostgreSQL, JWT httpOnly cookies, PDFKit
- Infrastructure: Docker Compose with PostgreSQL, backend, frontend

## Local Development

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

Seed demo data after PostgreSQL is running. First set `SEED_ADMIN_EMAIL`,
`SEED_DEMO_EMAIL`, and `SEED_DEMO_PASSWORD` in `backend/.env`; do not commit
real credentials:

```bash
cd backend
npm run seed
```

## Docker

```bash
docker compose up --build
```

Frontend: `http://localhost:5173`
Backend: `http://localhost:3001/api/health`

## Notes

- The CBAM countdown targets `2026-01-01`; after that date the UI correctly labels full enforcement as active.
- Demo calculator uses GLEC-inspired hardcoded factors and limits anonymous client-side use to 3 calculations.
- PDF reports are generated by the backend at `POST /api/reports/generate`.
